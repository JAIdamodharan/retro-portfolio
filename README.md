# Jaishree Damodharan — retro portfolio

Vite + React + TypeScript + Framer Motion.

```bash
npm install
npm run dev      # develop
npm run build    # production build in dist/
```

- Edit text, links and projects in `src/content.ts`.
- Media lives in `public/`: `hero.mp4` (compressed, 1280×720), `hero-poster.jpg`, `og.jpg` (link preview), `resume.pdf`.
- Easter eggs: press **G** to play, Konami code, poke the mascot 5×.
